# 验证说明

WindowHop 将规则自检、示例界面检查和真实窗口验证分开记录。自检通过不代表所有应用、系统版本和窗口类型都已兼容。

## 构建与规则自检

在符合 [构建要求](../README.md#从源码构建) 的环境中运行：

```sh
./Scripts/build.sh
./WindowHop.app/Contents/MacOS/WindowHop --self-test
codesign --verify --strict WindowHop.app
```

0.3.0 当前包含 362 项纯规则检查，涵盖快捷键与搜索状态、窗口命令及自动重复保护、布局与导航、排序与窗口身份、截图与放大预览几何、设置导入导出等。自检不发送系统事件、不启动全局监听、不操作真实窗口，也不注册登录项。

严格签名验证只检查应用签名的一致性，不表示经过 Apple 公证。

## 外观检查

使用示例数据生成截图，不需要捕获其他应用：

```sh
./WindowHop.app/Contents/MacOS/WindowHop \
  --demo --snapshot "$PWD/preview.png" \
  --appearance thumbnails --size medium --theme dark
```

`--appearance` 支持 `thumbnails`、`icons`、`titles`；`--size` 支持 `small`、`medium`、`large`、`auto`；`--theme` 支持 `light`、`dark`、`system`。截图运行使用隔离设置。

修改外观时，请检查浅色与深色、首尾项目标题居中、圆角边缘、小屏及较多候选的滚动。动画需实际观看连续过程，静态图片无法证明过渡平滑。系统的减少动态效果、减少透明度和增强对比度选项也需单独验证。

## 真实窗口检查

使用独立启动的应用副本，确认辅助功能权限；测试缩略图时另需屏幕录制权限，更改后退出并重新打开。建议使用自己创建的测试窗口和可丢弃内容。

| 范围 | 需要观察的结果 |
| --- | --- |
| 全局快捷键 | 从外部应用呼出，正反向选择，松键提交，Esc 取消；其他切换工具没有争用按键 |
| 聚焦与恢复 | 普通及最小化窗口成为正确前台目标；取消后不出现迟到聚焦 |
| 搜索与导航 | 应用名／标题／多词查询正确；编辑文字不触发窗口命令；查询取消顺序正常 |
| 窗口动作 | 最小化／恢复、全屏、隐藏／显示、关闭、正常退出作用于当前目标；保留目标应用自己的保存提示 |
| 捕获 | 图像比例正常；无权限、受保护内容或匹配有歧义时回退图标；最小化窗口不为截图而恢复 |
| 配置与系统 | 设置持久化、例外、导入导出、多屏、其他桌面、登录启动与系统辅助显示设置 |

记录版本与构建号、macOS、目标应用、操作路径和观察结果。已完成的样本与未覆盖场景应分别说明，不将旧版本结果算作新构建的逐项重测。

## 开发诊断

```sh
./WindowHop.app/Contents/MacOS/WindowHop --diagnose
./WindowHop.app/Contents/MacOS/WindowHop --trace
```

`--diagnose` 仅报告当前进程的权限与配置信息。从终端运行时，系统权限归属可能与 Finder 启动的独立应用不同，请同时检查应用设置页。

`--trace` 显式开启监听状态、耗时、动作与焦点校验等元数据日志，不记录窗口标题、正文或图像。普通启动不输出这些诊断。公开问题前仍应检查输出，移除与复现无关的本机信息。
